# 独立 PDF 的固定预算验证

从 MMLongBench-Doc 选择四份不同于此前干预试验的 PDF。三个调查报告和一份幻灯片各构造两道标签交换题及一道无关项题。按原始图表人工核对答案、像素交换框和参考图表框。人工框仅用于构造干预和诊断，不参与选图。文档是人工选例，结论适用于本轮机制验证。 [标注](heldout-cases.json)

在原始 PDF 上运行公开 ColPali v1.3，将前两页固定给所有方法和两种图像条件。每张图使用 216 个视觉 token，每次调用使用两张图，由冻结 Qwen2.5-VL-7B NF4 回答。原始 PDF 的文字层和 MinerU 布局用于索引阶段，原图和编辑图共享选区，因而测量的是固定检索下的读图反应。原页中的图外文字也保持原样。

| 方法 | 选图 |
| --- | --- |
| 整页 | 保留检索的两张整页 |
| 固定扩框 | 每页选择顶部图表组，上方保留 7% 页高 |
| 查询选择图表组 | 按问题词和图表组在原始文字及图注中的局部匹配排序，使用同样的 7% 页高 |
| 查询选择图表组并调整范围 | 与上一组共享图表排序。若 2% 到 7% 的额外区域含问题所需词，保留扩框，否则只留 2% |

查询排序按词在该页图表组中的逆频率加权，使用非数字词，图注与框中可用的原始 PDF 文字共同参与匹配。完全无匹配时使用整页。自动候选为空时也使用整页。规则在模型回答前固定。评测报告交换题原图和编辑图两者均正确、无关项两图均正确及目标页召回。只有联合正确率较固定扩框改善、改善出现在至少两份 PDF、且无关项得分保持时，才推进方法。与查询选图固定 7% 的对照用于确定调整范围有无独立收益。 [选择与评测实现](retrieval_probe.py)

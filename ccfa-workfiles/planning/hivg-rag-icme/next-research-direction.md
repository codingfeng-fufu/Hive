# 面向 ICME 2027 的跨页视觉证据绑定

2026-11-23。建议优先验证一个免训练的文档问答机制。先从图表的空间位置、图例、柱高或标注中读出中间键，再用这个键约束另一页的行、列或图表系列，最后将两处原始证据交给回答模型。候选贡献是约束两处证据指向同一对象、年份或类别，并用局部干预测量模型是否真的沿着这条关系取数。状态为待验证方法。 [ICME 2027 排期](plan.md)

## 动机和已观测证据

- **跨页证据覆盖可以作为动机。** MMLongBench-Doc 本地 1,091 题中，360 题标注了至少两页证据，281 题同时带有 Chart、Table 或 Figure 标记。这些是标注统计，视觉绑定的实际题量需要单独辨认。 [完整题集](../../../data/mmlongbench-full.json)
- **紧预算下存在选页空间。** 在 7 份开发文档的 50 道有标注题上，VisRAG 和 ColPali 的 Top-2 分别完整覆盖 36、38 题。19 道跨页题中二者的 Top-2 都是 9/19，Top-6 分别为 15/19 与 14/19。两个 Top-6 候选合并后每题有 6–11 页，覆盖 16/19。两者中任一单独完整覆盖的题也是 16 道。跨页题中，17 道标两页、1 道标四页、1 道标十五页。仅看这 17 道两页题，固定 VisRAG Top-6 的两页 oracle 是 15/17，原排序 Top-2 是 9/17。oracle 用金标选页，衡量预算内的覆盖空间。 [VisRAG 缓存](../../../runs/vger-pilot/visrag-rankings.json) · [ColPali 缓存](../../../runs/vger-pilot/colpali-rankings.json)
- **旧路由和实体合并的证据各自有限。** 同一批题的路径重放中，每条路径最多返回六个证据项。默认 QAHT、熵单独路由和全图 Micro-only 完整覆盖 14/50、17/50 和 19/50。熵阈值在同批开发题设定。图检索的六个证据项和页面基线的六张图有不同视觉 token 成本。VGER 在五份新 PDF 的 11 对同名异物中，生产定位双端命中 0 对，附加几何候选后命中 1 对，仍发生误合并。人工框下 11 对也都通过默认视觉阈值。当前证据支持保留长文档证据选择动机，暂缓以同名误合并作为投稿主线。 [熵路由重放](../../../runs/vger-pilot/routing-entropy/results.json) · [VGER 留出复验](../../experiments/vger-pilot/split-holdout-report.md)

## 免训练机制

1. 用冻结的页面检索器构建固定候选池。把候选页上的图、表和相邻标题作为区域候选，保留 PDF 页码和边界框。首版验证限定为一个需要视觉读取的中间键和一个目标图表，优先处理年份、类别和系列名。
2. 给冻结的 Qwen2.5-VL-7B 首跳候选，读出至多两个中间键假设，各自记录来源区域。用年份、行列标题或图表类别的匹配约束第二跳。标签缩写若需要对齐，使用文档内可核查的别名或由同一冻结模型复核候选，记录复核原文和位置。允许同一键出现在多页，由标题的指标与语境消歧。保留两个假设可检查首跳误读是否能被后续证据纠正。
3. 按首跳可信度、第二跳键相容性、目标题意及实际视觉 token 预算联合选择区域对。提供原始图表裁剪及解读必要的轴、图例或表头，记录证据对、键和最终答案。以目标区域可复核的绑定正确率作为模型回答以外的指标。

## 最近工作与差异

| 工作 | 已覆盖的机制 | 对当前方向的约束 |
| --- | --- | --- |
| n-Clue 受控研究 | 条件分解检索、不同页的最大最小覆盖分配、全条件与部分条件文档对照 | 条件覆盖本身已有研究。本方向验证同一文档中前一处图表读出的键能否决定后一处区域，并检验选区和答案是否随该键变化。 [论文及 §4](https://arxiv.org/html/2607.24165v1) |
| SimpleDoc、VLD-RAG、ViDoRAG | 迭代查询更新、缺失证据反馈、视觉候选复查和证据汇总 | 自由文本反馈是直接对照。方法需在相同候选、图像预算及模型调用数下证明，带原始区域的键约束可减少取错行列或系列。 [SimpleDoc §3](https://aclanthology.org/2025.emnlp-main.1443.pdf) · [VLD-RAG §3](https://arxiv.org/html/2607.24748v1) · [ViDoRAG §5](https://arxiv.org/html/2502.18017v2) |
| IRCoT | 已检索证据和推理中间结果驱动下一跳文本检索 | 中间结果驱动检索已有先例。待验证贡献落在两处视觉区域之间的可核查关联及其局部干预。 [论文](https://aclanthology.org/2023.acl-long.557/) |
| Doc-V*、Retrieval-Augmented Perception | 前者有缩略图、主动取页和工作记忆，后者免训练检索高分辨率裁剪、保留布局并适应性选择裁剪数 | 粗到细和高分辨率裁剪均有先例。全页与裁剪只是预算和输入表示的对照。 [Doc-V*](https://aclanthology.org/2026.acl-long.2129/) · [RAP](https://arxiv.org/html/2503.01222v2) |

另一个方向是单独做视觉证据使用诊断。保持检索页和题目相同，在保持布局的前提下替换有明确语义的年份、图例关系或目标值，并要求答案按规定变化。它复用上面的少量真题，可回答「答对是否真的用了这处图表」。正式扩展需要控制编辑痕迹、文本捷径和答案唯一性。作为 ICME 六页稿件，优先将它用于检验绑定机制。

## ICME 最小验证

先从剩余文档筛出足量可独立核查的例题，冻结开发、验证文档和视觉预算。用 7B 在同候选池上比较页面 Top-k、独立子问检索、自由文本两跳、显式键与源框的两跳。再用金标键与金标框分别估计绑定和定位上限。记录完整证据对准确率、原始题目答案准确率、替换键后答案按预期变化的比例，以及所有阶段视觉 token、总 prompt token 和延迟。用文档级配对区间呈现差值。

继续投入的依据是自然题中有可复核的样本规模，且显式绑定在等候选、等视觉预算、等调用数下同时提升证据对和答案准确率。若金标键也很少改善，或收益主要依赖人工首跳框，停止扩展这项方法。

**实测更新。** 5 道真实题的小试使用人工子问和证据定位。聚焦子问后，自由文本与显式绑定在裁剪图上均答对 5/5，在证据整页上均答对 3/5。裁剪图的替换键对照中，显式绑定在正确键和替换键两种条件下均符合预期的题数为 5/5，自由文本为 3/5。显式绑定的主张先保留在取值约束与可核查的证据上。 [小试报告](../../experiments/visual-binding-pilot/report.md)
